# תדריך כתיבת פעולות

פעולה במאגר היא **מקור השראה**, לא תסריט מחייב. המדריך פותח אותה בטלפון, מבין תוך 30 שניות מה קורה, ולוקח ממנה מה שמתאים לו.

---

## 1. עקרון המבנה

```
משחק ראשון  →  חוויה
משחק שני    →  חוויה שמעמיקה או מסבכת
משחק שלישי  →  הרגע שבו המטבע נופל
                ↓
              המסר
```

* שלושה משחקים - לא פחות ולא יותר.
* **המסר חייב לנבוע ממה שקרה במשחקים.** אם אפשר להחליף את שלושת המשחקים בשלושה אחרים והמסר יישאר זהה - הפעולה נכשלה.
* קשת אנרגיה טובה: פותחים גבוה (`high`), ממשיכים בינוני (`medium`), מסיימים נמוך (`low`) - ואז מדברים. לא חובה, אבל זה עובד.
* המשחק השלישי הוא הגשר. הוא צריך להיות המשחק שהכי קל לדבר עליו אחריו.

## 2. מה אסור

* **אין להמציא מקורות יהודיים.** אין ציטוט שאינך בטוח בו ב-100%, אין ייחוס למדרש או לרב. מוטב `sources: []`.
* אין מסר מטיף. מדריך בן 16 לא יגיד לחניכים "וכך נלמד שעלינו להיות טובים יותר". כתוב מסר שאפשר להגיד בקול רם בלי להתבייש.
* אין פעולה שדורשת יותר מ-20 דקות הכנה או ציוד שאין בסניף.
* **בפעולת שבת - כל שלושת המשחקים חייבים להיות `shabbat: true` במאגר.** הבדיקה האוטומטית פוסלת אחרת.
* אין להמציא משחקים חדשים בתוך הפעולה. משתמשים רק ב-id של משחקים שקיימים במאגר.

## 3. מבנה הרשומה

```json
{
  "id": "a-w14-shabbat",
  "title": "כותרת שאומרת משהו, לא 'פעולה לחנוכה'",
  "day_type": "shabbat",
  "week_index": 14,
  "date": "2026-12-12",
  "topic": "אור קטן בחושך גדול",
  "topics": ["courage", "faith"],
  "holiday": "חנוכה",
  "parasha": "וישב",
  "goal": "משפט אחד: מה החניך אמור לקחת מהפעולה הזאת",
  "games": ["g-ice-04", "g-coop-11", "g-quiet-07"],
  "connection": "2-4 משפטים: למה דווקא שלושת המשחקים האלה ובסדר הזה, ואיך המסר צומח מהם",
  "message": "המסר עצמו, 3-6 משפטים, בשפה שמדריך בן 16 יכול להגיד",
  "discussion_questions": ["שאלה שמחזירה לחוויה במשחק", "שאלה שמחברת לחיים שלהם"],
  "equipment": ["חבל", "מטפחות"],
  "preparation": "מה להכין לפני, או null",
  "duration_minutes": 60,
  "sources": []
}
```

### כללי שדות

| שדה | כלל |
|---|---|
| `id` | `a-w<מספר שבוע>-<tuesday\|shabbat>` למשל `a-w07-tuesday`. |
| `title` | כותרת עם אופי. לא "פעולה מספר 4". |
| `day_type` | `tuesday` או `shabbat` בלבד. |
| `week_index` | מספר השבוע בלוח `content/calendar/year-5787.json`. חובה - לפיו הפעולה נקשרת לתוכנית. |
| `date` | התאריך המדויק של אותו מועד מהלוח. |
| `topic` | הנושא בעברית, כפי שיופיע בתוכנית השנתית. |
| `topics` | מזהים מ-`taxonomy.json` בלבד, 1-3. |
| `holiday` / `parasha` | רק אם באמת רלוונטי. **מותר ורצוי `null`** - לא כל פעולה חייבת להיות קשורה לפרשה. |
| `games` | בדיוק 3 מזהי משחקים שקיימים במאגר, בסדר המשחק. |
| `connection` | הלב של הפעולה. בלי זה הפעולה היא רשימת משחקים. |
| `message` | 3-6 משפטים. קונקרטי, לא מליצי. |
| `discussion_questions` | 2-4 שאלות. הראשונה תמיד חוזרת למשחק ("מה הרגשתם כש..."). |
| `duration_minutes` | 45-75 בדרך כלל. |
| `sources` | `[{"text": "...", "ref": "..."}]` או `[]`. במקרה של ספק - ריק. |

## 4. חיבור ללוח השנה

* חג = הזדמנות, לא חובה. פעולה בשבוע של חנוכה כדאי שתדבר על חנוכה.
* פרשת שבוע = בונוס. אם יש חיבור טבעי - מצוין. אם החיבור מאולץ - `parasha: null` ולא מזכירים.
* ברוב שבועות השנה אין חג ואין נושא כפוי, ואז הנושא הוא חברתי-חינוכי: ערבות הדדית, שמירת הלשון, חברות, אחריות.
* בשבועות של ימי זיכרון - הפעולה צריכה להיות מדויקת ורגישה לגיל 12.

## 5. סגנון

* עברית פשוטה, משפטים קצרים. בלי מקפים ארוכים, בלי אימוג'ים בתוך הטקסט.
* פנייה למדריך, לא לחניך: "תשאלו אותם", "אל תמהרו לתת את התשובה".
* המסר נכתב כאילו אומרים אותו בקול, לא כאילו כותבים אותו בחוברת.
